# Contributing to Reportix

Thank you for your interest in contributing to Reportix! Whether it's reporting a bug, proposing a feature, or submitting code, your help is appreciated.

## How to Contribute

### Reporting Bugs and Requesting Features
* Use the built-in GitHub issue templates for [Bug Reports](.github/ISSUE_TEMPLATE/bug_report.yml) and [Feature Requests](.github/ISSUE_TEMPLATE/feature_request.yml).
* Check existing issues before submitting a new one to avoid duplicates.

### Submitting Code
1. Fork the repository and clone it locally.
2. Create a new branch for your feature or fix (`git checkout -b feature/your-feature-name`).
3. Install dependencies locally:
    ```bash
    pip install -r requirements.txt
    ```
4. Commit your changes with clear messages.
5. Push your branch and open a Pull Request against the `main` branch.

## Code Style Guidelines

* Keep code clean, readable, and well-commented.
* Test your changes locally to ensure PyQt6 UI elements and performance metrics function properly across platforms.
